# mock-api

A mock REST API for prototyping, testing, and development — powered by my-json-server from @typicode.

This repo contains a simple `db.json` file that acts as a fake API backend. It can be accessed online without any setup using the Typicode-hosted my-json-server.

---

## 🔗 Live API URL

You can use this fake API via:

https://my-json-server.typicode.com/uptype/mock-api

> Replace `/characters`, `/planets`, etc. as needed.

Example endpoints:

- [`/characters`](https://my-json-server.typicode.com/uptype/mock-api/characters)
- [`/characters`](https://my-json-server.typicode.com/uptype/mock-api/characters/4)
- [`/planets`](https://my-json-server.typicode.com/uptype/mock-api/planets)
- [`/starships`](https://my-json-server.typicode.com/uptype/mock-api/starships)
- [`/films`](https://my-json-server.typicode.com/uptype/mock-api/films)
- [`/affiliations`](https://my-json-server.typicode.com/uptype/mock-api/affiliations)

## 🛠 Want to self-host?

If you'd rather spin-up and run a local version instead of using the hosted version, clone this repo and run:

npm install -g json-server
json-server --watch db.json

Then access it at:
http://localhost:3000
